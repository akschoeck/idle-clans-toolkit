# Idle Clans Toolkit

## Rules

- **Gather fresh data from both the API and the wiki for every feature change.** Whenever you add a new feature, or update or upgrade an existing one, collect the data, mechanics and formulas it depends on from both sources, and do it again each time rather than relying on memory, notes or an earlier session:
  - the public API (`https://query.idleclans.com/api`, e.g. `/Configuration/game-data`, market prices, player profiles), and
  - the community wiki (`https://idleclans.wiki/w/<Page>`, read through the web-fetch agent because curl is blocked by Cloudflare).
